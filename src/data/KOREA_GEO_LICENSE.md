# 대한민국 시군구 경계 출처

- 생성 기준일: 2026-07-01
- 가공 원천: [vuski/admdongkor](https://github.com/vuski/admdongkor)
- 원 데이터: 통계청 통계지리정보서비스(SGIS) 행정경계
- 데이터 라이선스: CC BY 4.0 + 공공누리 제1유형(출처표시)
- 생성 코드 라이선스: MIT
- 좌표계: EPSG:4326
- 해상도: 웹 시각화용 light 단순화 경계

> 본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서
> 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공:
> vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로
> 배포됩니다.

이 파일은 최신 행정코드와 지도 시각화를 위한 단순화 자료입니다. 일부 형상은
실제 경계와 다를 수 있으므로 법적·측량·주소 판정 용도로 사용하지 않습니다.
공식 원본이 필요한 경우 도로명주소 전자지도 `구역의 도형` 등 해당 기관이
제공하는 최신 원본과 이용조건을 별도로 확인해야 합니다.

`koreaGeo.json`은 `npm run update:boundaries`로 다시 생성합니다. 생성 스크립트는
제물포구·영종구·서해구·검단구의 2026년 코드가 존재하고 폐지된 인천 코드가
남아 있지 않은지 검증합니다.
